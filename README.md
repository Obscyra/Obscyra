<sub>FEATURED PROJECT</sub>

# Quran Desktop

### A calm, capable Quran reader for your desktop.

Read the Madani Mushaf page for page, study verse by verse, or listen and follow along.<br/>
The complete Arabic text is bundled, so reading works offline from the first launch.

<br/>

[![Get Quran Desktop](https://img.shields.io/badge/Get%20Quran%20Desktop-c99b43?style=for-the-badge&logo=readthedocs&logoColor=060908&labelColor=0f3d33)](https://github.com/Obscyra/quran-desktop/releases/latest)
[![Live demo](https://img.shields.io/badge/Try%20the%20live%20demo-0f3d33?style=for-the-badge&logo=netlify&logoColor=f5efe0)](https://qurandesktop.netlify.app)
[![Source](https://img.shields.io/badge/Explore%20the%20source-060908?style=for-the-badge&logo=github&logoColor=f5efe0)](https://github.com/Obscyra/quran-desktop)
